Aspetto e sicurezza

Cloud e livello di sicurezza

Sincronizza tutti i tuoi dispositivi tramite un repository privato su GitHub. Nel cloud finisce solo un file cifrato: senza password principale e chiave segreta non è leggibile da nessuno, nemmeno da GitHub.

  1. Su GitHub crea un repository privato (per esempio cassaforte-dati).
  2. Crea un token a grana fine: accesso solo a quel repository, permesso Contents: Read and write.
  3. Incolla qui sotto repository e token.

Protezioni attive

  • Cifratura AES-256-GCMDati cifrati e autenticati; ogni salvataggio usa un valore casuale nuovo e viene riempito per non rivelare quante voci hai.
  • PBKDF2-SHA512, 1.000.000 di iterazioniRende lentissimo ogni tentativo di indovinare la password.
  • Chiave segreta a 160 bitSi aggiunge alla password: chi copia il file dal cloud non ha modo di provare a indovinarla.
  • Attese dopo i tentativi erratiDal terzo errore l'attesa raddoppia fino a 15 minuti.
  • Blocco automaticoPer inattività e quando lasci l'app. Le password mostrate si nascondono dopo 15 secondi, gli appunti si svuotano dopo 30.
  • Pagina blindataIl browser blocca script estranei e consente solo la connessione a GitHub.

Backup e trasferimento

Il backup è un file già cifrato: si apre solo con la password principale con cui è stato creato. Usalo per copiare le password su un altro dispositivo.

Installazione e dati

Le password sono salvate su questo dispositivo, cifrate con AES-256. Con il cloud attivo, una copia cifrata sta nel tuo repository privato su GitHub. Se cancelli i dati del browser perdi la copia locale (non quella nel cloud): fai comunque backup regolari.

Come averla su ogni dispositivo

Windows / Mac: apri il file con doppio clic (Chrome, Edge, Firefox, Safari).
Android: copia il file sul telefono e aprilo con Chrome.
iPhone / iPad: pubblica la cartella su un hosting https (es. GitHub Pages), poi Condividi → “Aggiungi a schermata Home”.
Ogni dispositivo ha la propria cassaforte: trasferisci i dati con il backup.
